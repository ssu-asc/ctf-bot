# ASC CTF Bot

Existing Cloudflare Worker handles Discord interactions; GitHub Actions handle CTF notifications. This brownfield change adds opt-in project interest rooms to the same bot without changing existing commands or notifications.

Approved 2026-09-23: web, pwnable, reversing, cryptography, forensics, other. One shared private room per field; no automatic subdivision. Reactions grant access, then members form project teams themselves (2–3 recommended, 4 maximum, one PM). Never delete channels/messages automatically.
